How this website is built

This portfolio is also a working example of a serverless AWS stack. The Angular app is served from the edge by CloudFront, and a TypeScript Lambda handles the API. Everything is deployed with AWS CDK.

Evolution

From Flask on Lambda to the edge

The first version was a Python Flask app that rendered every page inside Lambda. The rewrite moves the UI to static files on CloudFront. Pages now load from the nearest edge location, and Lambda runs only when the API is called.
